# NeuroPaper AI — Contexto maestro (resumen)

Fuente: documento de contexto entregado por el usuario el 2026-10-27. La auditoría con hechos verificados está en `AUDITORIA-2026-10-27.md`.

- **Qué es:** una plataforma para que estudiantes *comprendan* papers científicos, no solo los resuman.
- **Ciclo de aprendizaje:** comprender → recuperar sin mirar → aplicar → revisar errores → repasar.
- **Diferencial:** análisis basado en el documento, con evidencia verificable por página y sección, más recuperación activa y repaso.
- **Público hipotético:** universitarios que leen papers para clases y proyectos.
- **Hoja de ruta:** P0 funcionamiento → P1 confiabilidad (páginas y evidencia) → P2 aprendizaje → P3 validación y negocio.
- **Principio:** no añadir funciones solo porque la IA puede generarlas. Cada una debe resolver una necesidad, funcionar de forma confiable y medirse.
- **Regla de auditoría:** distinguir hechos, hipótesis y propuestas, y no asumir que una función anunciada funciona.
